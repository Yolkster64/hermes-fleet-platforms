# Hermes XCore Python Integration

This package integrates the large pasted XCore pseudo-bundle into runnable Python modules.

## Included modules

- `feature_pipeline.py`
- `routing_policy.py`
- `vector_store.py`
- `orchestrator.py`

## Matching schema

- `sql-learning/hermes_xcore_schema.sql`

## Notes

- This is a Python-first integration of the provided pseudo design.
- C#/C++ can interoperate at service boundaries (HTTP/gRPC) without changing this package layout.
