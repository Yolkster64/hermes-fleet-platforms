⚙️ What Happens Automatically
Step    What it does
Install    Creates the 4-partition secure VHDX, registers event-log source, deploys Quarantine + Containment VHDXes, sets firewall rules, generates DPAPI API token, starts API Guard + IPC pipe + port-watch loop
Run (immediate)    Executes the full 12-stage pipeline right now — sanitizes junk, checks WinRE, audits ports, enforces resources
Bootstrap task    Registers a one-shot scheduled task that fires on the very next Windows Update event and then self-deletes
Permanent tasks    UpdateTrigger (fires 5 min after every WU event) and StartupCheck (fires 3 min after every boot) stay registered forever
Dashboard    Opens WinREHealthDashboard.html in your browser automatically


After that first run, you never touch it again — every future update triggers it automatically.
