This directory stores raw pasted X-Tier bundles plus auto-extracted sections generated by:

- `scripts/x-tier/import_xtier_bundle.py`

Extraction targets:

- `scripts/x-tier/imported/` (PowerShell script sections)
- `python/x-tier/hermes_xcore/imported/` (Python module sections)
- `config/x-tier/imported/` (config/sandbox sections)
- `sql-learning/imported/` (SQL schema sections)

These are source-integrated artifacts from pasted bundles and may include pseudo-code that requires refinement before production execution.
